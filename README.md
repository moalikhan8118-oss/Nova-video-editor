# Nova Video Editor

A cross-platform Flutter starter for a professional video editor.

## Included in this first build
- Android + iOS project structure
- Premium dark UI
- Nova branding
- Home / Projects / Templates / Settings navigation
- Create Project flow
- Video, photo, PDF and audio import entry points
- Editor screen with preview area
- Timeline-style media strip
- Small icon-based editing tools
- Undo / redo UI
- Export UI
- Responsive Material 3 design

## Run
1. Install Flutter.
2. Run `flutter pub get`.
3. Connect an Android device/emulator or configure an iOS simulator.
4. Run `flutter run`.
